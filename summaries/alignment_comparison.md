# Archived alignment comparison: raw reads vs preprocessed reads

This is a historical comparison from before the pipeline was simplified. It
preserves the recorded raw-read and preprocessed-read alignment values below;
it is not regenerated by the current source code.

The current `src/align_reads.py` aligns preprocessed FASTQs with minimap2 and
writes BAMs to `results/alignments/` plus `results/alignment_summary.tsv`.
The historical `results/alignments_preprocessed/` files and
`results/alignment_summary_preprocessed.tsv` are reproducible intermediates
and are ignored by Git.

The preprocessed input is slightly smaller than the raw input because pairs
shorter than 14 nt after trimming and pairs with malformed UMIs are excluded.
The table's mapping percentages therefore use different denominators and
should be compared cautiously.
