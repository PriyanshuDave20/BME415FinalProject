# KHDRBS2 R168C project

BME415 final project comparing wild-type (WT) KHDRBS2 with the R168C cancer mutation.

There are two separate analyses:

1. **easyCLIP-seq pipeline** — asks whether R168C changes candidate RNA-binding regions or enriched sequence patterns.
2. **structural workflow** — asks whether R168C changes the local protein structure around residue 168.

## Data

- `raw_data/` contains the original 12 easyCLIP-seq FASTQ runs from GSE154168.
- `reference/` contains the GRCh38 genome and GENCODE v44 annotation.
- `results/` contains reports, tables, and figures.

### What Git keeps

Git tracks the raw inputs and final reports, tables, figures, and structural models. Large reproducible intermediates—trimmed FASTQs, BAM files, downsampled files, STREME machine output, and ColabFold working files—are ignored and can be regenerated by the scripts. The `results/comparison/baseline_rpm_6runs/` folder contains historical baseline reports; the current corrected comparison report is `results/comparison/comparison_summary.md`.

## EasyCLIP-seq pipeline

Run these commands from the project root, in order:

```text
py -3 src/load_prepare.py
py -3 src/preprocess_reads.py
py -3 src/align_reads.py
py -3 src/find_binding_regions.py
py -3 src/compare_conditions.py
py -3 src/motifs.py
```

Each script writes its outputs to `results/` and can be rerun. The pipeline:

1. validates and labels the FASTQ files;
2. trims adapters and stores UMIs in read names;
3. aligns the cleaned reads to GRCh38 with minimap2;
4. finds coverage-enriched candidate regions in 4 kb bins;
5. compares WT and R168C after UMI deduplication and matched-depth downsampling;
6. finds enriched motifs with STREME.

### Software needed

- Python 3 with `matplotlib` and `cutadapt`
- WSL Ubuntu with `minimap2`, `samtools`, `umi_tools`, and MEME Suite `streme`
- approximately 16 GB free space for generated pipeline files

The main final outputs are:

- `results/comparison/comparison_summary.md`
- `results/binding_regions/method_comparison.md`
- `results/motifs/motif_summary.md`
- figures in `results/comparison/figures/` and `results/motifs/figures/`

## Structural workflow

Run the numbered scripts in order:

```text
py -3 01_validate_sequences.py
py -3 02_inspect_structures.py
py -3 03_compare_structures.py
py -3 04_analyze_local_environment.py
py -3 05_generate_report.py
```

These scripts validate the WT and R168C sequences, inspect AlphaFold/ColabFold structures, compare RMSDs, inspect the local environment around residue 168, and write:

- `results/structural_analysis/structural_analysis_report.md`

`06_wt5_r5_investigation.py` is an optional follow-up investigation, not a required workflow step.

## Main conclusion

WT and R168C share most candidate binding regions and the same broad GC-rich motif families. After deduplication and downsampling, the apparent R168C excess is mainly explained by sequencing depth and PCR duplication. Structural predictions show no clear local backbone rearrangement near residue 168, but replacing exposed Arg168 with neutral cysteine removes a positive charge from an acidic surface pocket.

Candidate regions and motifs are descriptive results, not experimentally confirmed binding sites or statistical significance claims.
